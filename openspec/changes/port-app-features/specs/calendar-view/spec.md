## ADDED Requirements

### Requirement: The calendar's bar stays the same in both views
Switching between the planned view and the seasons view SHALL leave the navigation bar unchanged: the same title and the same switch in the same place. "Today" SHALL sit with the month, shown while another month or day is in view, and editing availability SHALL be a labelled row under the month.

#### Scenario: Switch views
- **WHEN** the user switches from the planned view to the seasons view and back
- **THEN** the switch stays in place and looks the same, and only the content below changes
